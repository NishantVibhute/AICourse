Concepts · Machine Learning

How did you learn what a dog is?

Way 1

Give the machine a rule

Rule: IF it has 4 legs
AND a tail → it is a dog

Now we show it a cat. 4 legs ✓ Tail ✓

Machine says: DOG ✗Wrong! A cat also has 4 legs and a tail. Good rules are hard to write.

Way 2

Show the machine many examples

Street dogLabradorPug German ShepherdPuppy+ 1000s more

Now we show it a cat.

Machine says: NOT A DOG ✓It looks different from all the dogs it has seen.

Machine Learning = Way 2. We do not write the rules. We show many examples, and the machine learns by itself. Children learn the same way!

Concepts · Machine Learning

How a machine learns: the mango example

A fruit seller wants a machine that can tell if a mango is ripe.

RipeNot ripe

1. Show examples

We give the machine 12 mangoes. For each one we say: ripe or not ripe.

Examples = training data

2. Machine finds the pattern

It draws a line. Yellow and soft = ripe. Green and hard = not ripe.

Pattern = model

3. Guess a new mango

A new mango comes. The machine uses the line to guess: ripe! Click on the chart to test your own mango.

Guess = prediction

Deep Learning: how face unlock works

Deep Learning uses a network with many layers, a little like our brain. Each layer finds something bigger.

What the machine sees

Your photo

1Photo becomes numbers
2Find lines
3Find eyes, nose, mouth
4Find the full face
5Give the answer

Why "deep"? Because there are many layers. Real networks can have 100+ layers.

    Using AI the right way · real cases

    When AI learns the wrong thing

    Amazon · 2018

    A hiring tool that was unfair to women

    Amazon made an AI to check job applications. It learned from 10 years of old hiring, where most people hired were men. So it gave lower marks to CVs with the word "women's". Amazon stopped using it.

    LessonAI copies what is in its data, even the unfair parts.

    MIT study · 2018

    Face AI that makes more mistakes on some faces

    Researchers tested face AI from big companies. How often it guessed gender wrong:

    Dark-skinned women
    34.7%
    Light-skinned men
    0.8%

    LessonTest AI on all kinds of people, not only some.

    Using AI the right way · real cases

    Privacy, fake videos and jobs

    Privacy · Clearview AI

    Your photos, used without asking

    A US company collected billions of photos from social media. It made a face search tool for police. Several European countries fined it.

    LessonEven public photos can be misused.

    Deepfake · Hong Kong · 2024

    The fake video call

    An employee joined a video call with his "boss" and team. All of them were fake, made by AI. He sent about US$25 million (over ₹200 crore) to scammers.

    LessonA face and a voice on screen are not proof any more.

    Tools · Google Colab

    What is Google Colab?

    Colab (short for Colaboratory) is a free tool from Google. You write Python in the browser, and Google's computer runs it.

    1 · Your laptop or computer
    In [1]:model.fit(X, y)✓ Model trained!

    Only a browser (Chrome) and internet are needed. Nothing to install.

    Your code goes to Google →
    2 · Google's computer (the cloud)
    • Runs your code for you
    • Has a free GPU (a fast chip for AI), with limits
    • Python and AI libraries are already installed
    ← Results come back

    So: Your laptop does almost no work. Even an old or slow laptop can train AI models with Colab!

    Tools · Google Colab

    Colab: 6 things to remember

    Shortcut

    Shift + Enter

    Runs the cell and moves to the next one.

    Order

    Run from top to bottom

    If you skip a cell, the next cell may show an error.

    Install

    !pip install

    Put ! before a command to install a library. Example: !pip install seaborn

    Idle

    It disconnects if idle

    If you do nothing for a while, Colab disconnects. Reconnect and run the cells again.

    Files

    Uploaded files are temporary

    Files in the Files panel are deleted when the session ends. Keep your data in Google Drive.

    Save

    Save a copy

    File → Save a copy in Drive, so the notebook is in your own Drive.
